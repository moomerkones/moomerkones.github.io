Inspired by Kroos & Küch, Introducing Echo Networks for Computational Neuroevolution (2026) — a recurrent network fully defined by a single connection matrix, evolved rather than trained. This demo runs a simplified, browser-friendly version of that idea on a toy 2D pattern instead of the original ECG task.
